[[brandtFacilitatingCollaborationDesign2004a]]
Rules set the boundaries for whats possible and also structure the play of the game. Shift from the goals of the design process to the rules of a game makes it easier to generate design moves. Further, restrictions on idea generation can improve the outcome. 

Playing by the rules plays down external factors like [[power relations]] between participants. 

[[brandtDesigningExploratoryDesign2006]]
[[User Game]] has [[Rules]] how stories are build using [[cards]]. Together with [[Turn taking]] they help level [[Power relations]]. 

Each mentioned game has explicit rules for participation. 

[[Tangible Game Material]] and [[Rules]] help bridge the gap between different languages of the participants. They create a [[common ground]] / [[Common language]] everyone can relate to.
