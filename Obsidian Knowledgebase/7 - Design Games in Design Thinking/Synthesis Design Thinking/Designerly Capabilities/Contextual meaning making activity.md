- **Contextual meaning making** As truth criterion. Addition frequent use of _empathy_, _human-centered_, _co-creation_ and _participatory design_ describe design as "meaning-making activity" [p.13] Design is measured based on value it offers to the context for which it is intended [p.13]. 
----
- **Contextual meaning making**: Major truth criterion or value associated with designerly thinking. Design is described as meaning-making activity. Primary goal is to create new artefacts that make sense in the context for which they are intended. Solution is measured based on the value it contributes to the context.
