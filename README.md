# Bachelorthesis "Design Games"

This repo contains the literature synthesis and latex source for the paper itself. Used literature is managed using a [Zotero Group](https://www.zotero.org/groups/6492165/bachelorarbeit-design-games)

## Research question

This paper aims to compose a literature review to obtain the title "Bachelor of Science" with a research question stated as follows: 
> Design Games and Their Application in Creative Processes  
> Literature review on design games in various creative processes, including fields outside of computer science.
> Comparative and summarizing description of design games in different domains of application, with examples for further clarification.
